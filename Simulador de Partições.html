Simulador de Partições

A memória é uma fita de 50 KB. Cada programa ocupa um pedaço contínuo dela. Quando chega um programa novo, o sistema olha a lista de áreas livres e escolhe uma, conforme a estratégia. É esse "escolher" que o nosso programa em C++ vai fazer.

1. Exercício 12 do livro, passo a passo

Memória inicial do exercício 12 (seção 9.7): A 5 KB, B 3 KB, livre 10 KB, C 6 KB, livre 26 KB. Escolha a estratégia e avance os passos.

    2. As três estratégias lado a lado

    O mesmo exercício, até o fim, com cada estratégia. Repare onde o programa E foi parar e no tamanho das sobras.

    3. Modo livre

    Crie programas e clique num programa na fita para terminá-lo. Quando duas áreas livres ficam vizinhas, elas se juntam numa só (a "junção de áreas livres" da seção 9.5.2).

    4. A mesma lógica em pseudocódigo

    Isto é o que o programa C++ vai fazer, só com o que você já viu nas listas: uma variável, um para e um se. A única diferença entre as três estratégias é a linha marcada.

    // procurar uma área livre para um programa de "pedido" KB
escolhida ← nenhuma
para cada área da memória, do início ao fim:
    se a área está livre e tamanho da área ≥ pedido:
        // First-fit : se escolhida = nenhuma           → escolhida ← área ; PARAR
        // Best-fit  : se escolhida = nenhuma ou área MENOR que escolhida → escolhida ← área
        // Worst-fit : se escolhida = nenhuma ou área MAIOR que escolhida → escolhida ← área

se escolhida = nenhuma:
    mostrar "não cabe: programa espera na fila"
senão:
    programa ocupa o começo da área escolhida
    o que sobrar vira uma nova área livre
